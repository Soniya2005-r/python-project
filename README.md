# Manual Testing Project (Python)

This project simulates manual test case execution using Python scripts.

## 📁 Structure

- `test_cases/` - Contains manual test cases written in Python
- `test_data/` - Sample data for testing
- `reports/` - Test execution reports
- `run_tests.py` - Script to simulate running manual test cases

## ▶️ Running Tests

```bash
python run_tests.py
